# Brawl Yard
Brawl Yard is an online multiplayer fighting game. It supports a variety of gamemodes, weapons, powers, and more!

## How to play
To play, just hop on the website [brawl-yard.github.io](https://brawl-yard.github.io/index.html), and start brawling.

## Contributing
Brawl Yard is an open-source project, so that means YOU can help us build this game! Take note however of the following guidelines:

- Try to keep everything self-contained in one file. (eg. index.html)
- Don't be afraid to use web-dependencies!
- There will be NO upload or sharing of ANY copyrighted asset(s).
